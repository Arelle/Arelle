Happy New Year from the Arelle team! We've been busy this month working on the latest releases to Arelle and the Arelle iXBRL Viewer.

The Arelle (2.21.3) release included a Calc1.1 Working Group update, performance improvements to CI, improvements to ESEF error messages and a new plugin integration test runner. It also included XULE runtime performance improvements and support for Python 3.12.

The Arelle Viewer (1.4.14) release included support for multi target documents and Python 3.12.

Its the busy season for regulatory validation updates, and we will be updating the Arelle validations accordingly.

To get involved with future work please join the Arelle team monthly standup on the fourth Tuesday of each month at 1400 UTC. Please [contact us][support-email] for meeting details.
