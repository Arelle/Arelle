title: April - May 2024 Update
date: 2024-05-30T14:52:44

We're excited to announce the beta release of the Arelle Python API! You can read all about it on our [documentation page][python-api].

In addition, Arelle now supports the latest US SEC Edgar Filing Manual (EFM) 24.1.1 update as well as additional DBA validation updates. We have also updated views to support the Calc 1.1 arc.

The Arelle Viewer version 1.4.27 was released, featuring data about the report creation software in the file information.

To get involved with future work please join the Arelle team monthly standup on the fourth Tuesday of each month at 1400 UTC. Please [contact us][support-email] for meeting details.
