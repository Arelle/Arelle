title: October 2024 Update
date: 2024-10-25T11:54:00
---

This month, the Arelle team has introduced support for Report Package 1.0 loading, enhancing the platform's capabilities for structured data reporting. Additionally, we've updated the platform to support the EDGAR 24.3.1 release and Extensible Enumeration 2 schemas over HTTPS.

The Arelle 2.33.0 release also includes:

- ESEF 2024 validation updates
- Bug fixes for ESEF SVG validation comments
- Improvements to the EBA HTML export plugin
- Resolution of extra columns in relationship set reports
- The Arelle Viewer 1.4.36 release includes a fix to the Calc 1.1 inspector

To get involved with future work, please join the Arelle team monthly standup on the fourth Tuesday of each month at 1400 UTC. Please [contact us][support-email] for meeting details.
