August development centered around the release of **Arelle 2.44.4**, introducing early support for upcoming regulatory updates, expanding regional validation frameworks, and improving platform build stability.

## Regulatory & Validation Enhancements

- **EDGAR 26.3 Support**: Added preview support for **EDGAR 26.3**, including `pythonmonkey` support required for the release.
- **ESEF & UKSEF Updates**: Integrated a **UKSEF validation framework** directly into the ESEF plugin, enabled per-national-regulator configuration for ESEF report file naming, and addressed ESEF iXBRL hidden-fact fixes.
- **EDINET Rules**: Fixed an issue with EDINET current-year and prior-year DEI fact detection.

## Platform & UI Improvements

- **macOS Font Display**: Added native macOS Tk fonts to resolve oversized text issues occurring on Tk 9.
- **Build Stability**: Strengthened build reliability, targeting Tcl/Tk 8.6 on macOS and Python 3.14.x on Windows.

## Developer Quality & Tooling

- **Linting Migration**: Transitioned our code linting workflow from `flake8` to `ruff`.
- **Code Maintenance**: Expanded code quality efforts with **more type hint coverage**.
