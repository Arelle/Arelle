July brings the release of **Arelle 2.43.0** and **iXBRL Viewer 1.5.0**, featuring a fresh redesign for the viewer alongside plugin architecture migrations, improved validation precision, and GUI enhancements.

## Validation & Compliance

- **EDGAR & ESEF Updates**: Updated support for **EDGAR 26.1.3**, initiated the migration of the ESEF plugin to the validation plugin architecture, and added **ESEF multi-target filing validation** alongside support for the **Finland authority**.
- **Data & Schema Accuracy**: Introduced the new `xbrl-xsdtests` suite for improved **XSD facet validation accuracy** (covering ordering, digits, length, enumeration, and timezone) and added **Table Constraints enum values & key metadata validation**.

## Platform & Usability Fixes

- **GUI Package Manager**: Enhanced user workflow with **multi-select support** and auto-saving on close.
- **Rendering & Resilience**: Implemented a **multi-target table linkbase rendering fix** and improved package loading resilience when encountering invalid metadata.
- **Developer Health**: Expanded code quality efforts with **more type hint coverage**.

## Arelle iXBRL Viewer (v1.5.0)

- **Interface Redesign**: Delivered a complete **redesign of ixbrl-viewer (1.5.0)**, which is now fully integrated and consumed by Arelle.
