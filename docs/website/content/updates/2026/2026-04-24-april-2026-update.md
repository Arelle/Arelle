In April, the Arelle team released version **2.39.11**, introducing important regulatory finalizations, significant deployment optimizations, and internal code refactoring.

## Compliance & Validation

- **ESEF 2025**: Finalized support for the **ESEF 2025** reporting cycle.
- **ESEF Authority Option**: Introduced a new --esefAuthority configuration option across both the CLI and GUI.
- **xBRL-CSV Support**: Added metadata validation for **xBRL-CSV Table Constraints**.

## Performance & Infrastructure

- **Windows Performance**: Significantly improved Windows startup performance, reducing launch time to **1–3 seconds**.
- **DockerHub Availability**: The official Arelle Docker image is now published to DockerHub. It can be run using:  
  docker run arelleproject/arelle:latest /opt/start.sh
- **Installer Enhancements**: Refined the Arelle installer, successfully **cutting its size in half**.
- **Proxy Integration**: Implemented improved proxy support for better environment compatibility.

## Architecture & Code Quality

- **Refactoring**: Separated core responsibilities by extracting the PackageManager and PluginManager into distinct classes.
- **Type Hints**: Continued code modernization with **more type hint coverage** across the codebase.
