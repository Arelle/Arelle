We missed our monthly update in May as members of the team were attending the **2026 XBRL Europe and Eurofiling conference in Paris**. It was fantastic to connect in person with so many members of the Arelle community and to provide a preview of our upcoming Arelle viewer redesign.

Following that productive event, we are pleased to share our latest updates with the release of **Arelle 2.41.5**. This version introduces key regulatory updates, expanded API capabilities, and refined validation accuracy.

## Standard & Regulatory Compliance

- **EDINET 2026 Support**: Added support for **EDINET 2026** along with new filing validations.
- **ESEF 2025**: The **ESEF 2025 disclosure systems** are no longer marked as draft.

## Data & Validation Accuracy

- **Table Constraints**: Implemented **Table Constraints restriction validation**.
- **Negative-Number Check**: Improved the accuracy of the **iXBRL 1.1 negative-number check**.
- **OIM XSD Validation**: Added **XSD type validation** for CSV and JSON Open Information Model (OIM) formats.

## System & Infrastructure Upgrades

- **Public API Addition**: Exposed the **PackageSource** class as part of the public API.
- **Docker Updates**: Resolved an issue to ensure that **Docker images report the correct release version**.
- **Windows Installer**: Added **system-wide shortcuts** to the Windows installation process.
- **Typing Improvements**: Continued expanding code health with **more type hint coverage**.
