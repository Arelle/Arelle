In March, the Arelle team released version **2.39.3**, focusing on formula performance optimizations, validation updates, and new deployment and automation features.

## Performance & Infrastructure

- **Solvency II Performance**: Optimizations to the formula engine delivered up to **60% faster performance for Solvency II** taxonomies.
- **Web Server Docker Image**: Introduced an official **web server Docker image** (thanks to Ryan for this contribution).

## Validation & Compliance

- **EDGAR 26.1**: Added full support for the **EDGAR 26.1** release.
- **Rule Refinements**: Implemented several **KVK and EDINET validation rule improvements**.

## Platform & Tooling

- **Validation Exit Codes**: Added the validationExitCode option to allow returning non-zero exit codes when validation errors occur, aiding pipeline automation.
- **Data Parsing**: Introduced an **xBRL-CSV Table Constraints parser** to handle complex table layouts.
- **Codebase Improvements**: Continued adding **more type hints** to improve code stability and developer experience.
