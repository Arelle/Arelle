October has been a productive month for the Arelle project, marked by the release of **Arelle 2.37.67** and **iXBRL Viewer 1.4.77**. These releases focus heavily on expanding regulatory coverage, resolving developer pain points, and refining the user interface.

## Core Validation & Compliance

- **EDGAR Alignment:** Full support is now available for **EDGAR 25.3 & 25.3.1**.
- **ESEF Progress:** Implemented **improved ESEF validations** to streamline European reporting.
- **EDINET Expansion:** Added **60+ more EDINET validation rules**, pushing our total coverage to **87%**.
- **Conformance Testing:** Updated the **XBRL dimensions conformance suite** within our CI environment.

## API & Developer Enhancements

- **Session API:** Added **source zip stream filename detection** to the Session API.
- **Debugger Stability:** Resolved a bug where the ModelObject was causing the Python debugger to crash.
- **Data Export:** Implemented key bug fixes for the **fact table XML output format**.

## iXBRL Viewer (v1.4.77)

- **Better Navigation:** Dimensions in the **Fact Properties panel** are now sorted, making it significantly easier to read and explore distinct data points.
