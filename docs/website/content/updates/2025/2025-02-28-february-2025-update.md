This month’s updates focus on expanding validation support and enhancing the viewer experience, laying groundwork for upcoming regulatory changes and documentation improvements.

Arelle 2.36.16 includes:

- EDGAR 25.1 preview builds
- Bug fix for ESEF 1.4.1 data type checks
- New option to add filenames to server POST requests
- Continued expansion of DBA validation rules

iXBRL Viewer 1.4.59 introduces:

- Support for persisting user language selection
- New documentation project and early release of a user guide

To get involved with future work, please join the Arelle team monthly standup on the fourth Tuesday of each month at 1400 UTC. Please [contact us][support-email] for meeting details.
