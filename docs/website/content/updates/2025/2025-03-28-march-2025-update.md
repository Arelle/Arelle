title: March 2025 Update
date: 2025-03-28T13:05:00

March development focused on finalizing EDGAR 25.1 support, tightening ESEF conformance, and enhancing the accuracy and display of unit information across the platform.

Arelle 2.36.32 includes several updates:

- EDGAR 25.1 support
- ESEF 3.4.6 log locator reference handling
- Fixes for the EBA table report plugin
- DBA validation improvements
- Option for deduplicated facts when saving to OIM
- GUI bug fixes for calculation view

The iXBRL Viewer (1.4.62) now uses symbols from the UTR for all units—not just currencies—making non-monetary data like shares and percentages easier to interpret.

To get involved with future work, please join the Arelle team monthly standup on the fourth Tuesday of each month at 1400 UTC. Please [contact us][support-email] for meeting details.
