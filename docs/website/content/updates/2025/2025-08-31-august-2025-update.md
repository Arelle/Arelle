date: 2025-08-31T12:00:00

In August, the Arelle team released several updates across versions 2.37.43 through 2.37.53, focusing on enhancements to validation and data handling. Key updates included:

- **Validation and Conformance**: The recognition of ROS 2025 taxonomies was added, and both the EFM and the new UKSEF conformance suites were updated.
- **EDINET Rules**: New EDINET entries were added, and existing ones were updated for better efficiency.
- **Error Handling**: Improvements were made to the ErrorManager and logging for embedded SVGs.
- **Fact Handling**: A new function was created to replace old duplicate fact checks, and logging was added for duplicate fact set fact references.
- **Dependencies**: Various dependency updates, including frequent Python and GitHub Action updates.

To get involved with future work, please join the Arelle team monthly standup on the fourth Tuesday of each month at 1400 UTC. Please [contact us][support-email] for meeting details.
