title: July 2025 Update
date: 2025-07-31T12:00:00

The Arelle team delivered several updates in July 2025, from versions 2.37.29 through 2.37.42. The updates centered on extending validation and making various technical improvements to the platform. Key updates included:

- **EDINET Validation**: The initial EDINET validation plugin and conformance suite were added, along with numerous EDINET rules.
- **Validation Improvements**: The team added a new check for the extension taxonomy directory prefix for DK ESEF and improved the handling of test case variations with warnings.
- **Platform Enhancements**: New features were introduced, such as support for logging image CSS selectors and a new function to get file sizes.
- **Bug Fixes**: Fixes were addressed for issues like ROS.19 casting errors and a parenthesis grouping problem in the ROS.19 rule.
- **Dependencies**: The minimum version of setuptools was bumped, and various dependency groups were updated.

To get involved with future work, please join the Arelle team monthly standup on the fourth Tuesday of each month at 1400 UTC. Please [contact us][support-email] for meeting details.
