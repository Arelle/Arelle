title: June 2025 Update
date: 2025-06-30T12:00:00

In June, the Arelle team released multiple updates across versions 2.37.19 through 2.37.28, which focused on expanding validation, improving platform infrastructure, and handling new features. Key updates included:

- **NL-KVK rules**: Numerous new validations were added.
- **Infrastructure**: The Python Session API was promoted from beta, and Mac builds were separated for Intel and Apple Silicon.
- **Conformance Suites**: The ability to pass test case filters to the conformance suite runner was added, and the EFM conformance suite was updated for 25.2.
- **OIM Taxonomy**: Improvements were made to OIM Taxonomy typing, and how the OIM taxonomy plugin was loaded.
- **Bug Fixes**: A fix was implemented to handle None fact values when deduplicating facts.

To get involved with future work, please join the Arelle team monthly standup on the fourth Tuesday of each month at 1400 UTC. Please [contact us][support-email] for meeting details.
