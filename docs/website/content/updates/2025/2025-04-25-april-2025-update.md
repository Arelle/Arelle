In April, the Arelle team delivered a series of infrastructure-focused updates, most notably adding support for Python 3.13 across both the platform and iXBRL Viewer.

Arelle 2.37.3 updates include:

- Added support for Python 3.13
- Introduced a new `--inlineTarget` CLI argument to specify inline target sets (e.g., `--inlineTarget=DKGAAP`)
- Fixed a bug related to formula parameter resolution for iXDS target documents
- Improved support for EBA 4.0, including fixes for loading xBRL-CSV files
- Resolved an issue affecting behavior when running Arelle as a Windows service

The iXBRL Viewer also now supports Python 3.13, ensuring continued alignment with the latest platform infrastructure.
